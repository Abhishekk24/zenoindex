    How it works

    Three parts, one flow

    Contracts

    A factory clones a vault per basket. Deposits mint shares at NAV, redemptions burn them and pay out net of the exit fee, which a FeeEscrow splits between platform and manager. A Uniswap v4 adapter routes rebalancing swaps.

    API

    Reads every basket from Arc in batched calls, prepares unsigned transactions for the app, and checks each mined transaction matches what was prepared before it confirms an order.

    App

    Explore baskets, invest and redeem as an investor; switch to Manager Mode to create a basket, set weights, seed it and claim fees. Signing stays in your wallet.

    What works on testnet today

    Deposits, redemptions, fee accounting, basket creation and manager tools are live. The stock tokens in the demo basket are test tokens without Uniswap liquidity yet, so baskets hold deposits in USDC and redeem in USDC until pools are seeded. Prices are set by the admin and refresh daily.

    ETHGlobal

    Built on earlier work, ported to Arc at the hackathon

    ZenoIndex started on Robinhood Chain before the hackathon. At ETHGlobal we ported it to Arc: Arc builds of the contracts and their deployment, Arc support in the API and app, fixes for Arc's USDC gas and RPC limits, this site and the Android release. The repository keeps the full original history so judges can see exactly which commits came when; the README lists them.
